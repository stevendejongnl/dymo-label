# dymo-label

Tkinter label maker for the Dymo LetraTag LT-200B, with bold, italic and strikethrough formatting and a live preview.

## Requirements

- Python 3 with Tkinter and Pillow
- `dymo_bluetooth` on the PATH
- The label maker paired over Bluetooth

## Usage

    python3 dymo-label.py

Type the label text, apply formatting with the B, I and S buttons, then press Print.
